# Cisco Toolbox — v1.0.0

## English

**Cisco Toolbox** is a native Windows app for configuring Cisco switches and routers — connect over SSH or Serial, then click buttons instead of typing raw IOS commands from memory.

### Highlights

- 🔌 **SSH / Serial** in one interface, with a live terminal — SSH login is handled by the standard `ssh` client (Windows' own OpenSSH, or a bundled copy)
- 🧰 Dedicated tabs for **Basic hardening, Line VTY/Access, SSH, VLAN, Interface, Trunk, ACL, Management, Save & Verify, Factory Reset, and ROMMON/password recovery**
- 📌 **Pin Commands** — build your own personal shortlist from any command in the app, with export/import
- 📤 **Import / Export** — pull a device's running/startup config to a file, or push a saved config file back to it
- 🔒 **Black Box** — a password-protected, encrypted notebook for your switches' hostnames, usernames, secrets, and enable secrets
- 🔍 Search across **every tab at once**, not just the one you have open
- 🎨 Custom app icon, splash screen, and the Roboto font throughout the UI

### Downloads

Grab `CiscoToolboxSetup.exe` below and run it — it installs the app to Program Files with a Start Menu shortcut and a proper uninstaller. No Python installation needed.

### Feedback

Found a bug or have an idea? Please open an issue, or use the **Email Me** button in the app's About dialog.

## فارسی

**Cisco Toolbox** یه برنامه‌ی بومی ویندوزی برای پیکربندی سوییچ و روتر سیسکوئه — از طریق SSH یا Serial وصل شو، و به‌جای تایپ دستورهای خام IOS از حفظ، روی دکمه‌ها کلیک کن.

### نکات مهم این نسخه

- 🔌 **SSH / Serial** در یک رابط کاربری، با یه ترمینال زنده — لاگین SSH توسط کلاینت استاندارد `ssh` (OpenSSH خودِ ویندوز، یا یه نسخه‌ی همراهِ برنامه) مدیریت می‌شه
- 🧰 تب‌های اختصاصی برای **سخت‌سازی پایه، Line VTY/Access، SSH، VLAN، Interface، Trunk، ACL، Management، Save & Verify، Factory Reset، و ROMMON/بازیابی پسورد**
- 📌 **Pin Commands** — از هر دستوری توی برنامه، لیست شخصی خودت رو بساز، با قابلیت خروجی/ورودی گرفتن
- 📤 **Import / Export** — کانفیگ running/startup سوییچ رو به یه فایل خروجی بگیر، یا یه فایل کانفیگ ذخیره‌شده رو دوباره بهش وارد کن
- 🔒 **Black Box** — یه دفترچه‌ی رمزنگاری‌شده و محافظت‌شده با پسورد برای هاست‌نیم، یوزرنیم، سکرت و enable secret سوییچ‌هات
- 🔍 سرچ در **همه‌ی تب‌ها همزمان**، نه فقط تبی که همون لحظه بازه
- 🎨 آیکون اختصاصی برنامه، اسپلش‌اسکرین، و فونت Roboto در سراسر رابط کاربری

### دانلود

فایل `CiscoToolboxSetup.exe` رو از پایین همین صفحه دانلود کن و اجراش کن — برنامه رو توی Program Files نصب می‌کنه، یه shortcut توی Start Menu می‌سازه، و یه Uninstaller درست‌وحسابی هم داره. نیازی به نصب پایتون نیست.
